Nominal ini otomatis dipakai untuk menghitung kolom "Denda" di Data Pinjaman ketika angsuran lewat jatuh tempo. Jasa/bunga pinjaman tetap diisi manual per transaksi di form Tambah Pinjaman (karena biasanya beda-beda tiap nasabah).

Bantuan & Petunjuk Penggunaan

🚀 Alur Kerja Dasar (urutannya penting!)

  1. Tambah Nasabah dulu — buka menu Data Nasabah → isi Nama, No HP, NIK (wajib 16 angka), alamat. Ini wajib sebelum bisa bikin pinjaman.
  2. Buat Pinjaman — buka menu Data Pinjaman → "+ Tambah Pinjaman" → pilih nasabah dari dropdown → pilih Paket (tenor & fee otomatis terisi) → isi jumlah pinjaman → simpan.
  3. Tagih & Catat Pembayaran harian — tiap hari buka menu Penagihan Hari Ini untuk lihat siapa saja yang harus ditagih, atau langsung pakai "Input Pembayaran" di halaman Data Pinjaman (pilih nama → nominal otomatis terisi → simpan).
  4. Pantau lewat Dashboard — cek Piutang Aktif, Total Dana Keluar, Jasa Diterima, dan grafik kapan saja.

📋 Penjelasan Tiap Menu

Dashboard — ringkasan total dana keluar, piutang aktif, jasa diterima, jumlah telat, dan grafik jasa per bulan.

Data Nasabah — data master peminjam (Nama, NIK, alamat, catatan). Status pembayaran (Lancar/Telat) dihitung otomatis dari riwayat pinjamannya, tidak perlu diisi manual.

Penagihan Hari Ini — daftar semua pinjaman yang jatuh tempo hari ini atau sudah telat. Ada tombol "Sudah Ditagih" dan kolom catatan manual (misal "janji bayar besok").

Data Pinjaman — semua transaksi pinjaman: tambah baru, bayar angsuran, lihat jadwal cicilan (ikon 📅), kirim pengingat WA (ikon 💬), hapus (ikon 🗑️), dan Export/Laporan PDF.

Pengaturan — ganti password, atur nominal denda per hari/minggu telat, dan kelola tanggal merah/hari libur (Minggu otomatis libur, tidak perlu diinput).

❓ Pertanyaan Umum

Kenapa nama nasabah tidak muncul di dropdown form pinjaman?

Pastikan sudah ditambahkan di menu Data Nasabah dulu. Nasabah yang sudah Lunas semua pinjamannya tetap muncul (untuk pinjaman baru), tapi kalau masih ada pinjaman aktif otomatis tetap tampil.

Kenapa data yang saya tambah di Supabase langsung tidak muncul di app?

Tutup dan buka ulang app, atau tarik untuk refresh. Kalau masih belum muncul, coba clear cache browser (lihat panduan yang pernah dikirim).

Bagaimana cara backup data?

Buka Data Pinjaman → tombol "📄 Laporan / Export" → "⬇️ Backup ke CSV/Excel". File CSV bisa langsung dibuka di Excel/Google Sheets.

Muncul pesan error "Could not find column..." atau app blank/error terus?

Biasanya ada tabel/kolom di database Supabase yang belum dibuat. Screenshot error-nya dan kirim, nanti dibantu cek SQL yang perlu dijalankan.
